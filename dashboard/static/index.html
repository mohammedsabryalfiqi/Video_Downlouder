      🚀 تشغيل البوت لأول مرة

      ثلاث خطوات فقط من الصفر للعمل

      1. 1
        ثبّت المكتبات
        pip install -r requirements.txt
      2. 2
        جهّز ملف البيئة وضع توكن @BotFather
        cp .env.example .env

        python -m bot

      /startالرسالة الترحيبية مع أزرار القائمة

      /aboutنبذة عن البوت
      /statsإحصائيات فورية (للمشرفين)
      /ban <id>حظر مستخدم (للمشرفين)
      /unban <id>إلغاء حظر مستخدم (للمشرفين)
      /broadcast <نص>إذاعة لكل المستخدمين (للمشرفين)
